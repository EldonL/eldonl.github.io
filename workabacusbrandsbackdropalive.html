At Abacus Brands Inc, our company goes to many trade shows and events. We wanted to create an app the would allow us to create interactive experiences for our backdrops. We also wanted to be able to track the performance of each backdrop and capture leads. Therefore, we created Backdrop Alive, an app that allow users to scan the backdrop and unlock AR Experiences, mini games, and rewards. We also have a backend system that allows us to track the performance of each backdrop and capture leads. I was one of the developers on this project, and I was responsible for implementing the core gameplay mechanics, integrating the visual assets, and assisting with the backend system for tracking and lead capture. I also had to make sure the app was optimized for both iOS and Android, and that it was easy for users to scan the backdrops and unlock the experiences. I also had to work closely with the artists and designers to make sure the app looked good and was easy to use. I used ARFoundation(ARCore for android, ARKit for iOS) to implement the scanning of the backdrops. I set up a system that allowed us to easily add new backdrops without having to update the app. I also helped setup a system where user can customize their minigames by setting up a color palette, where selecting a color changes a minigame's primary and secondary colors. I set up a place where user caan create a new lead, edit the leads, name, notes, image and priority. The user can archive, delete and read the leads. In addition to the lead. It is also important for user to know which event they found the lead in. User can create an event and choose the date by interacting with a calendar, edit the name of the event and choose a location. They can also archive, delete and read the event as well.
